## Clarified Requirement

Implement the bounded `M-042/W-0114` access-token payload wrapper and route-protection slice authorized by `ADR-0053`.

The implementation may add the request-level Protobuf payload wrapper, generated Go Protobuf output, Protobuf adapter wrapper handling, application-owned route policy, an authentication validation handoff adapter, and focused tests.

## User-Visible Outcome

Protected runtime routes now have an application boundary that requires an explicit access-token proof wrapper and validated player identity before domain dispatch.

## Non-Goals

- Do not change the existing Protobuf envelope.
- Do not parse HTTP `Authorization` headers, Bearer tokens, cookies, query strings, or WebSocket subprotocols.
- Do not add WebSocket handshake authentication.
- Do not add session persistence.
- Do not wire process startup.
- Do not change repository interfaces, PostgreSQL adapters, or migrations.
- Do not add dependencies.
- Do not add logout, refresh, cleanup, token rotation, or broader production authentication behavior.
